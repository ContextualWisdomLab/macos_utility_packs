# macOS AI 개발 환경 자동화 한국어 매뉴얼

이 프로젝트는 새 Mac에 AI 개발 도구, 공용 MCP 서버와 스킬, 언어별 격리
환경, 셸, 모니터링, 컨테이너, VPN, 소규모 Kubernetes 실습 환경을
설치합니다. macOS 14 이상 Apple Silicon과 Intel Mac을 지원합니다.

## 빠른 시작

1. 터미널을 열고 저장소로 이동합니다.
2. 먼저 변경 예정 항목을 확인합니다.

   ```bash
   ./bootstrap --dry-run
   ```

3. 전체 설치를 실행합니다. Xcode Command Line Tools 설치 창이 나오면
   완료한 뒤 같은 명령을 다시 실행합니다.

   ```bash
   ./bootstrap
   ```

4. 새 터미널을 열어 `.zshrc` 설정을 적용합니다.
5. 계정 로그인을 진행합니다.

   ```bash
   ./bootstrap auth
   ```

6. 결과를 진단합니다.

   ```bash
   ./bootstrap doctor
   ```

같은 명령을 다시 실행해도 관리 블록과 MCP 항목이 중복되지 않습니다.
기존 사용자 설정과 설치된 스킬은 삭제하지 않습니다.

## 설치되는 핵심 도구

- 패키지 기반: Homebrew, Git, GitHub CLI
- AI CLI: Codex, Google Antigravity CLI(`agy`), Claude Code, GitHub
  Copilot CLI
- 에디터: Visual Studio Code
- 언어 격리: `mise`, `uv`, Node 24, Temurin JDK 21, Corepack, `pnpm`,
  Go, Rust, .NET 8, LLVM, CMake, Ninja, Conan
- 셸: Starship, zoxide, fzf, ripgrep, fd, bat, eza, direnv, atuin
- 모니터링: glances, btop, dust, duf, procs
- 컨테이너: Colima, containerd, nerdctl
- Kubernetes: kubectl, Helm, k9s와 별도 Colima k3s 프로필
- VPN: Passepartout, OpenVPN

대부분은 [`config/Brewfile`](../config/Brewfile)에서 Homebrew로 관리합니다.
CodeGraph와 Ponytail처럼 Homebrew 패키지가 아닌 통합만 공식 npm/플러그인
경로를 사용합니다.

## 단계별 실행

필요한 부분만 실행할 수 있습니다.

```bash
./bootstrap --only packages,shell
./bootstrap --skip skills
./bootstrap skills
./bootstrap mcp
```

주요 단계 이름은 `preflight`, `homebrew`, `packages`, `languages`, `shell`,
`containers`, `skills`, `extensions`, `mcp`, `instructions`입니다.
`--verbose`는 진단 로그를 늘리고 `--yes`는 비밀정보가 아닌 확인 질문을
자동 승인합니다.

## MCP와 Figma

다음 서버를 Codex, Claude Code, Antigravity, VS Code, Copilot CLI에
공통 등록합니다.

- Sequential Thinking
- Time
- DeepWiki
- Context7
- Memory
- CodeGraph
- Figma 공식 원격 MCP (`https://mcp.figma.com/mcp`)

Codex와 Claude는 각 CLI의 MCP 관리 명령을 사용합니다. Antigravity의
공식 전역 파일 `~/.gemini/config/mcp_config.json`에는 원격 서버를
`serverUrl` 형식으로 변환합니다. Antigravity,
VS Code, Copilot은 사용자 JSON 설정에 관리 서버만 병합합니다. 기존의
다른 MCP 서버는 보존하고 변경 전 설정은 상태 디렉터리에 백업합니다.

Figma는 OAuth 로그인이 필요합니다. `./bootstrap auth` 안내 후 각
클라이언트의 MCP 메뉴에서 `figma` 서버를 선택하고 브라우저 로그인을
완료합니다. 토큰은 저장소나 스크립트에 입력하지 마세요.

## Ponytail과 CodeGraph

Ponytail은 MCP가 아니라 에이전트 플러그인과 스킬입니다. 공용 스킬로
설치하고 Codex, Claude, Copilot에서 지원되는 플러그인 명령도 실행합니다.
Antigravity와 VS Code/Copilot 에이전트는 공용 스킬 및
`~/.agents/AGENTS.md` 지침을 읽습니다.

CodeGraph는 글로벌 CLI와 MCP 서버로 설치합니다. 공용 지침은 저장소에
들어갈 때 `.codegraph/` 인덱스가 없거나 오래되었으면 별도 요청을
기다리지 않고 다음 명령을 실행하도록 에이전트에 요구합니다.

```bash
codegraph init -i
```

인덱싱은 `.gitignore`, 비밀정보, 생성 결과물을 존중해야 하며 실패했다고
사용자 데이터를 임의로 삭제해서는 안 됩니다.

## 공용 skills.sh 스킬

`./bootstrap skills`는 `find-skills`를 명시적으로 포함하고, 실행 시점의
skills.sh Official API 및 모든 Topic 페이지에서 스킬 목록을 수집합니다.
중복을 제거한 뒤 `~/.agents/skills`를 공용 위치로 사용하여 Codex,
Claude Code, Antigravity, Copilot 등에 연결합니다.

목록이 매우 크므로 첫 설치는 네트워크와 시간이 많이 들 수 있습니다.
부분 실패 시 성공한 스킬은 유지하고
`~/.local/state/macos-ai-bootstrap/skills-report.json`에 실패 목록을
남긴 뒤 비정상 종료합니다. 다시 실행하면 재시도할 수 있습니다.

## Python, Java, Node 격리

Python 프로젝트:

```bash
uv init
uv venv
uv add requests
uv run python main.py
```

Java/Node 프로젝트는 `mise.toml`에 버전을 고정합니다.

```bash
mise use node@24
mise use java@temurin-21
corepack enable
pnpm install
```

프로젝트 의존성을 시스템 Python, 시스템 Java 또는 임의의 글로벌 npm
경로에 설치하지 마세요. Python은 `.venv`, Node는 lock file, Java는
빌드 도구의 프로젝트 캐시를 사용합니다.

## Go, Rust, .NET/C#, C/C++ 격리

Go와 Rust, .NET SDK 버전도 `mise.toml`에 고정합니다.

```bash
mise use go@latest
mise use rust@stable
mise use dotnet@8
```

Go는 프로젝트별 `go.mod`와 `go.sum`, Rust는 Cargo workspace와
`Cargo.lock`, .NET/C#은 solution-local project와 local tool manifest 및
NuGet lock file을 사용합니다.

C와 C++에는 Python식 virtualenv가 없습니다. Homebrew LLVM을 컴파일러로
쓰고, 프로젝트별 CMake build directory 및 Conan profile/lockfile로
의존성과 ABI 설정을 격리합니다.

```bash
cmake -S . -B build -G Ninja
cmake --build build
conan profile detect --force
```

## AI-native 셸과 모니터링

설치기는 `.zshrc`에 이름이 표시된 관리 블록만 추가합니다. Homebrew,
mise, direnv, Starship, zoxide, atuin, fzf와 현대적 명령 별칭을
초기화합니다. 사용자의 블록 밖 설정은 그대로 둡니다.

```bash
glances
btop
dust
duf
procs
```

glances를 백그라운드 서비스로 자동 실행하지 않으므로 필요할 때만
자원을 사용합니다.

## containerd와 nerdctl

Docker Desktop과 Podman은 설치하지 않습니다. Colima 템플릿은
containerd를 선택하며 기존 사용자 템플릿이 있으면 덮어쓰지 않습니다.

```bash
colima start --runtime containerd
nerdctl run --rm hello-world
colima stop
```

기본 템플릿은 CPU 4개, 메모리 8GiB, 디스크 60GiB입니다. 설치 후 Colima
설정을 직접 조정할 수 있습니다.

## 소규모 Kubernetes 시험 환경

평상시 컨테이너 프로필에는 Kubernetes가 꺼져 있습니다. 시험할 때만
별도 `macos-ai-k8s` 프로필을 시작합니다.

```bash
./bootstrap kubernetes
kubectl get nodes
helm version
k9s
```

자원값을 바꾸려면 실행 전에 환경변수를 지정합니다.

```bash
BOOTSTRAP_K8S_CPU=2 \
BOOTSTRAP_K8S_MEMORY=4 \
BOOTSTRAP_K8S_DISK=30 \
./bootstrap kubernetes
```

종료와 삭제:

```bash
colima stop --profile macos-ai-k8s
colima delete --profile macos-ai-k8s
```

삭제 명령은 해당 프로필의 Kubernetes 데이터도 제거하므로 사용자가 직접
결정해서 실행해야 합니다.

## Passepartout와 OpenVPN

Passepartout GUI와 OpenVPN CLI를 Homebrew로 설치합니다. VPN 프로필,
인증서, 사용자 이름, 비밀번호는 민감정보이므로 이 저장소가 관리하지
않습니다. 조직이 제공한 프로필을 Passepartout에 가져오거나 다음처럼
OpenVPN을 직접 실행합니다.

```bash
sudo openvpn --config /안전한/경로/profile.ovpn
```

VPN 프로필을 Git에 커밋하지 마세요.

## 세벌식 한국어 IME와 Left Shift + Space

구름 입력기를 추가 설치하는 대신 macOS가 공식 지원하는 내장
`3-Set Korean (390)` 입력기를 기본으로 사용합니다. 먼저 시스템 설정 →
키보드 → 텍스트 입력 → 편집에서 `ABC`와 `3-Set Korean (390)`을
활성화하세요.

Homebrew로 설치한 Hammerspoon 설정은 **Left Shift + Space**를 누르면
두 입력기 사이를 전환합니다. Hammerspoon을 한 번 실행하고 시스템 설정 →
개인정보 보호 및 보안 → 손쉬운 사용에서 권한을 허용해야 합니다. 오른쪽
Shift+Space는 가로채지 않습니다.

다른 세벌식 이름을 쓰려면 Hammerspoon 실행 전에 지정할 수 있습니다.

```bash
export MACOS_AI_KOREAN_INPUT_METHOD="3-Set Korean"
```

실험 단계인 온글(Ongeul) 같은 대안도 있지만, 이 설치기는 macOS 14+
Apple Silicon/Intel에서 공식 지원되고 별도 IME 업데이트가 필요 없는
내장 입력기를 선택합니다.

## AI 작업 중 절전 방지

상시로 macOS 절전을 끄지 않습니다. 내장 `caffeinate`를 감싼 `ai-awake`
명령은 AI 프로세스가 실행되는 동안에만 시스템과 디스플레이 절전을
막고, 프로세스가 끝나면 원래 정책으로 복귀합니다.

```bash
ai-awake codex
ai-awake claude
ai-awake agy
ai-awake copilot
```

인자도 그대로 전달할 수 있습니다.

```bash
ai-awake codex exec "테스트를 실행하고 실패를 수정해"
```

## 인증과 비밀정보

`./bootstrap`은 토큰을 요구하지 않습니다. `./bootstrap auth`는 GitHub,
Codex, Claude, Antigravity의 대화형 로그인만 시작합니다. Copilot은
대화형 세션에서 `/login`, Figma는 각 MCP 화면에서 OAuth를 완료합니다.

`.env`, API 키, OAuth 토큰, VPN 프로필과 인증서를 저장소에 넣지
마세요. 로그의 token/key/secret/authorization 형태 값은 가립니다.

## doctor 결과 읽기

```bash
./bootstrap doctor
```

`REQ-01`부터 `REQ-20`까지 `pass` 또는 `fail`로 출력합니다. JSON 결과는
`~/.local/state/macos-ai-bootstrap/doctor.json`에 저장됩니다. 로그인만
남은 원격 MCP는 설치 실패와 구분해서 클라이언트의 MCP 메뉴에서
확인합니다.

## 문제 해결

Homebrew가 새 셸에서 보이지 않으면:

```bash
source ~/.zshrc
brew --version
```

Xcode 도구 설치가 대기 중이면 설치 창을 완료하고 `./bootstrap`을 다시
실행합니다.

스킬 설치가 일부 실패하면 네트워크를 확인하고 `./bootstrap skills`를
다시 실행한 뒤 `skills-report.json`을 봅니다.

MCP 서버가 나타나지 않으면 클라이언트를 완전히 종료해 다시 실행하고:

```bash
./bootstrap mcp
./bootstrap doctor
```

CodeGraph가 보이지 않으면 `command -v codegraph`와 `pnpm bin --global`을
확인합니다. Colima 문제가 있으면 `colima status`와 `colima logs`를
확인합니다.

설정 백업은 `~/.local/state/macos-ai-bootstrap/backups`에 있습니다.
설치기는 사용자 패키지나 임의 설정을 제거하지 않으므로, 복구는 백업을
확인한 뒤 해당 관리 단계를 다시 실행하는 방식이 기본입니다.

## Git Flow

저장소는 `main`, `develop`, `feature/*`, `release/*`, `hotfix/*` 흐름을
사용합니다. 기능 개발은 `develop`에서 `feature/...` 브랜치를 만들고,
검증 후 병합합니다. 커밋 메시지는 Conventional Commits 형식을
사용합니다.
